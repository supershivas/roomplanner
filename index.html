Sélectionne un objet, dessine un contour de pièce ou ajoute un élément.

Créer

En mode « Dessiner les murs », clique pour placer les angles, puis clique près du premier point pour fermer la pièce. En mode sélection, double-clique sur un mur pour saisir sa longueur. En mode dessin, double-clique pour terminer un contour ouvert.

Pièce

Clique sur un mur pour modifier ses sommets, ou dessine une nouvelle pièce. Les dimensions sont exprimées dans les unités du plan (cm si tu utilises les valeurs par défaut).

Pour ajouter un point, sélectionne un mur puis clique sur « Ajouter un point ». Pour le supprimer, sélectionne d’abord son sommet.

Propriétés de l’objet

La hauteur est la dimension verticale de l’élément. L’élévation est la hauteur de sa base par rapport au sol.

Porte

0–100 % correspond à une ouverture de 0 à 120°.

Éléments du plan

    Aucun objet ajouté.

    Raccourcis

    Suppr : supprimer l’objet sélectionné
    Échap : quitter le mode dessin
    Ctrl/Cmd + Z : annuler
    Glisser : déplacer un objet ou un sommet
    Maj pendant le dessin : aligner le mur horizontalement ou verticalement
    Vue 3D : glisser un objet pour le déplacer ; glisser le fond pour tourner ; molette pour zoomer

    Dessine une pièce depuis zéro, puis passe en vue 3D. Les fenêtres créent une ouverture réelle dans les murs.
