    Rendu temps réel : lumières physiques, ombres portées, éclairage du ciel par les fenêtres. Les lampes et spots du plan éclairent la scène ; le soleil entre par les ouvertures.

      Raccourcis
      • V : sélection · W : murs · O : poser un objet · M : mesure
      • Suppr : supprimer · Ctrl+D : dupliquer · Échap : quitter l’outil
      • Ctrl+Z / Ctrl+Y : annuler / rétablir · flèches : déplacer de 1 cm (Maj : 10 cm)
      • Murs : Entrée ou double-clic pour terminer, Retour arrière pour retirer le dernier point, Maj pour aligner
      • Plan : molette pour zoomer, glisser le fond pour se déplacer
      • 3D : glisser un objet pour le déplacer, glisser le fond pour tourner, molette pour zoomer
