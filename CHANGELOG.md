# Historique des versions

## 1.5.0 — 2026-10-26
- Le panneau de droite n'affiche plus que les propriétés de la sélection (objet, colonne, lumière ou pièce) ; sans sélection, le plan prend toute la largeur
- Barre d'outils : « Ajouter » (catalogue avec icônes), « Pièce » et « Éléments » (liste) ; réglages du rendu dans la vue 3D ; menu Aide avec les raccourcis
- Couleurs en palette flottante, champs sur trois colonnes, options rares repliées ; sur mobile, feuille en bas de l'écran

## 1.4.0 — 2026-10-26
- Verrouillage des objets, des colonnes, des lumières et des murs : ils restent sélectionnables mais ne bougent plus (cadenas sur le plan)
- Nouveaux objets : porte-fenêtre, table à repasser, commode, radiateur, lampe de bureau (elle éclaire en 3D réaliste)
- 3D réaliste : le plafond arrête la lumière, le jour n'entre plus que par les fenêtres et portes-fenêtres, plus vive côté soleil

## 1.3.0 — 2026-10-26
- Rendu 3D réaliste : lumière du jour selon l'heure, ombres douces, lampes et spots physiques, ciel par les fenêtres, image PNG
- Interface alignée sur les autres apps : menus Fichier / Édition, vues Plan et 3D, roue crantée « Réglages » avec version et nouveautés
- Le plan s'enregistre tout seul dans le navigateur ; export et import JSON dans les Réglages
- Plan : murs avec cotes, mesure, zoom et déplacement de la vue, portes qui s'ouvrent comme en 3D, lumières visibles et déplaçables
- Hauteur sous plafond réglable ; mise à jour automatique avec toast

## 1.2.0 — 2026-10-23
- Palette de 20 couleurs pour les objets, colonnes, murs et sources lumineuses
- Sources lumineuses personnalisées (spots, lampes, ambiance), enregistrées dans le JSON
- Cadrage initial 3D plus proche de la pièce
