# Historique des versions

## 1.3.0 — 2026-10-26
- Rendu 3D réaliste : lumière du jour selon l'heure, ombres douces, lampes et spots physiques, ciel par les fenêtres, image PNG
- Interface alignée sur les autres apps : menus Fichier / Édition, vues Plan et 3D, roue crantée « Réglages » avec version et nouveautés
- Le plan s'enregistre tout seul dans le navigateur ; export et import JSON dans les Réglages
- Plan : murs avec cotes, mesure, zoom et déplacement de la vue, portes qui s'ouvrent comme en 3D, lumières visibles et déplaçables
- Hauteur sous plafond réglable ; mise à jour automatique avec toast

## 1.2.0 — 2026-10-23
- Palette de 20 couleurs pour les objets, colonnes, murs et sources lumineuses
- Sources lumineuses personnalisées (spots, lampes, ambiance), enregistrées dans le JSON
- Cadrage initial 3D plus proche de la pièce
